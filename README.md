# System Automation & CLI Tools

Herramienta de línea de comandos (CLI) desarrollada en Python para la automatización de tareas del sistema operativo, ordenamiento de directorios desordenados y clasificación inteligente de archivos según su tipo y extensión.

## Características
- **Organización Automática:** Clasifica archivos sueltos en carpetas temáticas (Documentos, Imágenes, Scripts, Comprimidos).
- **Creación Dinámica de Directorios:** Genera las carpetas necesarias según el tipo de archivo detectado.
- **Soporte CLI:** Permite pasar cualquier ruta del sistema mediante argumentos.

```bash
python organizer.py /ruta/a/tu/carpeta
